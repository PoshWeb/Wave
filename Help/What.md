# What is Wave?

Wave is a powerful open-source audio toolkit, written in PowerShell.

PowerShell runs on Windows, MacOS, and Linux, and so we can make Waves on any platform.

Wave lets you sample, sequence, and synthesize waves.

Wave helps us all work with waveforms.

## What is a Wave?

Waves are just a series of samples over time.

Sound waves are pressure waves.

The amount of pressure at any given moment is the amplitude.

The rate at which the wave is changing is it's frequency.

This is fundementally what a sound is: just a series of changes over time.

## What is a Wave File?

In 1991, Microsoft and IBM codified the [Wave File Format](https://en.wikipedia.org/wiki/WAV).

This became _the standard_ for uncompressed audio.

It's got a [minimal format header](Wave-File-Format.md), a place to put metadata, and the rest is all waves.

Wave gives us a way to work with `.wav` files in memory.

## What Can We Do?

So very much :-)

At it's core, `Wave` is a `DAW` ([Digital Audio Workstation](https://en.wikipedia.org/wiki/Digital_audio_workstation))

Wave allows us to sample, sequence, and synthesize waves.

It does this within PowerShell, a powerful scripting language with an object pipeline.

This allows us to make sounds of all shapes and sizes within a scripting language that can do anything.

We can literally make waves.

The goal is to make waves easy to understand and work with.
